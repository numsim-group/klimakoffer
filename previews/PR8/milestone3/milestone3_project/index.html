Milestone 3 - Solving a zero-dimensional Energy Balance Model

Solving a zero-dimensional Energy Balance Model

(Download description in PDF format)
(Download The_World128x65.dat)
(Download True_Longitude.dat)

In the previous milestones you have already implemented some routines that are part of an energy balance model. Now you have the opportunity to combine your results into a zero-dimensional (0D0D0D) energy balance model (EBM) and solve the model using an ODE solver. Note that for zero-dimensional EBMs, spatial dependence is neglected, and TTT is a global time-dependent averaged surface temperature. Let the following equation be given for the energy balance model:

C‾∂TA(t)∂t+A+BTA(t)=Ssol‾(t),\begin{aligned} \overline{C}\frac{\partial {T}_A(t)}{\partial t}+A+B{T}_A(t)=\overline{S_\text{sol}}(t), \end{aligned}C∂t∂TA​(t)​+A+BTA​(t)=Ssol​​(t),​

where C‾\overline{C}C is the mean heat capacity, TA{T}_ATA​ is an approximation to the area-average of the time dependent temperature, AAA the CO2CO_2CO2​ dependent radiative cooling, B=2.15B = 2.15B=2.15 the feedback effects such as water vapor cycles, lapse rate and cloud cover, Ssol‾(t)\overline{S_\text{sol}}(t)Ssol​​(t) is the area-averaged solar forcing. To solve the zero-dimensional EBM you should proceed as described in the next steps.

  1. Implement a function calc_area, which determines the area fraction of each grid cell as a function of latitude, with an equidistant step size h=π64h=\frac{\pi}{64}h=64π​ for a 128×65128 \times 65128×65 grid, and returns the values as a vector.

  2. Implement a calc_mean function, using the results from the first task, which takes a matrix of values of a given parameter like albedo or solar forcing for each grid cell and returns the mean value over the whole area.

  3. Write a function calc_radiative_cooling_co2, which returns the CO2CO_2CO2​ dependent radiative cooling AAA for a given CO2CO_2CO2​ concentration ccc. As default value use the CO2CO_2CO2​ concentration of the year 1950: c0=315.0c_0 = 315.0c0​=315.0. The radiative cooling AAA is given by

A(c)=210.3−5.35log⁡(cc0)\begin{aligned} A(c) = 210.3-5.35 \log\left(\frac{c}{c_0}\right) \end{aligned}A(c)=210.3−5.35log(c0​c​)​

  1. In a function compute_equilibrium, solve the above equation (1) using the forward Euler method and calculate an average temperature per year until equilibrium is reached.

  2. Write a new function or adapt your existing one to add an option to solve the equation with the backward Euler method instead. Plot your results.
